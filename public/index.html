New Feedback Template

                
            

            
            

                
Student's name. Write {{name}} anywhere in the template and it is replaced with the student's first name each time you apply the template.

                
Point deductions. Write (-N) — for example (-1) or (-2.5) — to take N points off the question's maximum. Every marker in the feedback box is highlighted and their total is subtracted, so on a 10 point question (-2.5) plus (-1) scores 6.5. The score box turns read-only while any marker is present, and clearing them all resets the question to ungraded. This works only on questions you score by typing a number, not on rubric or bubble questions.
